One joke about Monday mornings — "Monday morning, my bed filed for custody of me — and honestly, the judge would side with the bed." — not a complaint and not an alarm-clock cliche: the bed itself sues for custody. A tiny Node program writes it to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
